# Drafting documentation

## Titles and headings

- Write headings so a reader can reconstruct the page from them alone.
- Use sentence case for headings; capitalize only the first word and proper nouns.

## Structure and flow

- Lead each page with its most important fact, in the first paragraph.
- Split a paragraph that needs a transition word such as however or additionally.
  It is carrying two ideas.
- Write in active voice.
  Passive voice hides the actor and adds words.

## Paragraphs and lists

- Give a numbered list to procedures and a bulleted list to everything else.
- Put exactly one action in each numbered step.

## Callouts

- Reserve warning, caution, and note callouts for safety-critical or non-obvious facts.
  Routine notes belong in prose.
- Keep a page to two callouts or fewer.
  More callouts than that make the page itself the warning.

## Images

- Never embed copy-paste text such as a URL, token, or command inside an image.
  Text inside an image cannot be selected, searched, or diffed.
- Write alt text as a prose description of the image, never "image of X" or "diagram".
