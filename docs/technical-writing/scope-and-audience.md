# Defining scope and audience

## Content type selection

- Give a page one purpose: getting started, how to, reference, concept, or troubleshooting.
- A how-to over 10 steps signals the task needs to change, not just the writing.
- Name a troubleshooting entry with the exact error text, not a paraphrase.
  A reader pastes the error into search and expects a match.
- Order troubleshooting entries by frequency or workflow position, not alphabetically.

## Information architecture

- State a fact in one page only.
  A section copied into a second page drifts the moment one copy changes.
- Give a task that spans pages a clear start, a defined next step, and a verifiable end.
